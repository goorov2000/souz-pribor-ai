# HTTP API

Контракт локального приложения. Основной запуск — в [README](../README.md).



```bash
curl http://127.0.0.1:8000/api/health
curl http://127.0.0.1:8000/api/examples
curl http://127.0.0.1:8000/api/examples/dm02/result
curl -X POST http://127.0.0.1:8000/api/generate \
  -H 'Content-Type: application/json' \
  --data-binary @examples/dm02.input.json
```

Вход `ProductInput`:

```json
{"name":"Прибор","manufacturer":null,"specs":{"питание":null},"description":null,"enrich":false}
```

`name` — обязательная непустая строка до 250 символов. `manufacturer` — строка до 250 или null; `description` — строка до 12 000 или null. `enrich` — булево значение, по умолчанию false в API. При true выполняется поиск по точной модели на сайте производителя; в веб-форме поиск изначально включён. Отсутствующие необязательные поля допустимы. `specs` — объект до 60 строк: имя до 150 символов, значение — строка до 1000, конечное число либо null. Булевы, массивы, вложенные объекты и посторонние верхнеуровневые поля отвергаются. Пробелы по краям очищаются, техническая запись и единицы не пересчитываются. Максимум тела запроса — 32 000 байт.

JSON-редактор браузера отклоняет целые вне диапазона −9007199254740991…9007199254740991 и переполнение чисел. Передавайте точные большие значения строками в кавычках, например `"9007199254740993"`. Все допустимые имена характеристик, включая `__proto__`, сохраняются при работе с формой.

Для генерации обязателен `Content-Type: application/json` (параметр `charset` допустим). Если передан `Origin`, он должен совпадать со схемой, локальным адресом (`localhost`, `127.0.0.1` или `[::1]`) и портом самого запроса. Сторонние Origin и `Origin: null` отклоняются до вызова модели, даже если подменён Host. Собственный локальный UI и curl без Origin работают.

Успешная карточка: `{status:"draft", card, counts, metadata, exports}`. `card` содержит `seo_title`, `seo_description`, `characteristics` (`name`, `value`, `source`, `quote`), `search_queries`, `commercial_block`, `missing_fields`, `warnings`. Для исходных `specs` источник — `specs`, цитата — null; для извлечённых фактов — `name` или `description` и точная цитата. Для найденных в документации — `web`, `source_url` и проверенная цитата. У отсутствующих характеристик источник и цитата — null. `product_identity` сохраняет название и производителя, `enrichment` разделяет происхождение и число новых полей, `research` при включённом поиске содержит его исход, источники, факты и расхождения. Пропуски обозначаются путями полей, например `specs.питание`. Значение 0 сохраняется, пустая строка и null превращаются в «данных нет». Числовые значения таблицы отображаются строками.

Нехватка сведений — HTTP 200 с `status:"needs_data"`, `message`, `missing_fields`, `next_steps`, `api_called`, без `card` и `exports`. Если описание и значения характеристик пусты или прямо помечены как неизвестные, ответ формирует сервер, `api_called:false`, ключ не требуется. При непустом, но бедном источнике это может определить модель: добавляются `summary` до 600 символов, `known_characteristics`, `warnings`, `metadata`, `api_called:true`. Это справка о необходимых дополнениях, а не SEO-карточка; требование 800–1200 символов применяется к `draft`.

SEO-строки очищаются от краевых пробелов до проверки длины; пустое описание не принимается. `counts` вычисляет Python по фактически выдаваемым строкам: Unicode-символы с пробелами. `metadata` включает `provider`, `model`, `attempts`, суммарный `usage` обеих попыток и границы проверки. `exports.json` — сериализованный `card`, `exports.markdown` — готовый текст. Ответ ошибки: `{"error":{"code":"…","message":"…"}}`, без сырых ответов провайдера.

Статусы: 403 — недопустимый Origin; 415 — неверный Content-Type; 422 — неверный ввод, отказ или непрошедший проверку черновик; 413 — большой запрос; 429 — лимит API или занятый процесс; 503 — отсутствует ключ; 504 — таймаут; 502 — ошибка сети, прав, модели, сервиса, пустой или обрезанный ответ. Локально выполняется одна генерация одновременно. `GET /api/health` сообщает готовность конфигурации, не проверяет баланс или доступность API. Статика отдаётся только из `static/`, примеры выбираются из фиксированного списка.
