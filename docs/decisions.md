# Технические решения

[README](../README.md) · [HTTP API](api.md) · [Приёмка](acceptance.md)

## Стек и границы прототипа

FastAPI предоставляет локальные HTTP-маршруты; Pydantic проверяет данные; HTTPX обращается к OpenAI Responses API. Интерфейс написан на обычных HTML/CSS/JavaScript и не требует сборки. Для одного рабочего экрана база данных и отдельная система управления контентом не нужны.

Приложение слушает loopback-адрес. Авторизации и открытого интернет-деплоя нет. `sessionStorage` текущей вкладки сохраняет ввод и предыдущий результат; постоянное хранение обеспечивают скачиваемые файлы.

## Разделение генерации и проверки

Рабочий промпт — [app/prompts.py](../app/prompts.py). Инструкции находятся в system-сообщении, сериализованный товар — в отдельном сообщении с пометкой недоверенных данных. Промпт задаёт русский B2B-стиль, обязательные блоки и запрет восстанавливать свойства по аналогам или исполнять команды из описания.

Модель возвращает строгий объект по JSON Schema: статус, SEO, запросы, commercial-блок, извлечённые факты с цитатами, недостающие поля и конфликты. Сервер строит таблицу, сохраняет исходные значения, проверяет длины, цитаты и часть технических обозначений. После нарушения есть одна попытка коррекции. Повторный неуспех возвращается как ошибка, без искусственного обрезания или растягивания текста.

`draft` требует SEO-заголовок 1–70 и описание 800–1200 символов. `needs_data` означает отдельную краткую справку до 600 символов. Если содержательного источника нет, сервер сообщает о нехватке данных ещё до обращения к модели.

## Выбор модели и API

Настроена `gpt-6-luna`; модель задаётся через `OPENAI_MODEL`. Используется `POST /v1/responses`, `store=false`, строгая схема, `reasoning.effort=none`. Лимит вывода карточки — 6000 токенов, поиска — 9000. Сравнительный бенчмарк моделей не проводился, превосходство по качеству не заявляется.

Ключ читается только сервером из окружения или игнорируемого `.env.local`. Сырые ошибки провайдера не передаются в браузер. Сетевые сбои, таймауты, отказ модели, ограничения доступа, пустой и обрезанный ответы имеют отдельные понятные сообщения. HTTPX-таймаут задаётся на сетевые операции и не является обещанием общей длительности всей генерации.

## Два режима источников

В базовом режиме `enrich=false` технические значения берутся только из входных `name`, `description`, `specs`. Это режим исходного задания. Для извлечённого факта значение должно входить в дословную цитату из соответствующего поля. Ноль считается известным значением; `null` и пустая строка — пропуском.

Дополнительный режим `enrich=true` реализован в [app/enrichment.py](../app/enrichment.py). Отдельный запрос с поиском ищет точную модель и производителя. Сервер скачивает найденные HTML/PDF, проверяет цитату и идентификацию, затем сохраняет у новых фактов `source=web`, `source_url` и `quote`. Документы соседних моделей и неподтверждённые цитаты исключаются в пределах реализованных проверок. Расхождения не заменяют исходное значение молча: оба варианта сохраняются для уточнения.

Поиск ограничен одним запросом к провайдеру, пятью инструментальными вызовами, тремя документами и 60 кандидатами фактов. Недоступность документа или неоднозначность модели показывается явно. У загрузки документов отдельные ограничения по HTTPS, адресам, размеру, перенаправлениям и времени; ключ OpenAI туда не передаётся.

В API поиск по умолчанию выключен; в форме включён. Исходный JSON без `enrich` при загрузке в форму может включить поиск, поэтому для базового сценария его нужно снять явно.

## Что означают проверки

JSON Schema подтверждает форму ответа. Проверка токенов и цитат помогает обнаружить часть неподтверждённых утверждений, но не доказывает истинность смысла. Знакомое число можно связать с неверным свойством, а документ — неверно истолковать. Материалы, единицы и противоречия проверяются ограниченными правилами. Редактор остаётся последним этапом перед публикацией.

Технические тесты подменяют внешние ответы, чтобы воспроизводимо проверять поведение сервиса без API-расходов. Сохранённые живые результаты имеют дату и хеши исходного кода; их не следует считать новым прогоном текущего снимка. [Подробности приёмки](acceptance.md).

Usage записывается в метаданные генерации. Число токенов не равно числу символов. Стоимость зависит от текущего тарифа, поиска и повторов; фиксированная цена карточки не заявляется. У обычного сервера нет общего денежного бюджета проекта.
