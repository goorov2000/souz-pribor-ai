# Дизайн-система · СОЮЗ-ПРИБОР

Пользователь предоставил логотип и сохранённую публичную страницу компании и выбрал светлую тему. Канонические правила — в [DESIGN.md](../DESIGN.md). Старые варианты Carbon и Linear сохранены только в истории работы.

Фирменные синий и красный получены из публичного CSS сайта, а не выбраны по похожему оттенку. SVG сохранён без изменения цветов и геометрии. Метаданные — `static/brand/sources.json`.

Шрифт Inter Variable с латиницей и кириллицей поставляется локально. Основной текст 14 px, подписи 12 px, поля 34–40 px; радиусы 5–8 px. Красный выделяет создание карточки; остальные действия спокойнее по цвету и весу.

## Рабочий экран

Примеры находятся в верхней части экрана. Название и производитель объединены в строку; ниже расположены характеристики и документация. Предпросмотр выделен отдельной панелью с собственным прокручиванием. Служебные сведения об источниках доступны в раскрываемых блоках; подтверждённые данные и экспорты не теряются.

Мобильная версия сохраняет порядок «данные → черновик», показывает фирменный логотип и крупный ввод. Навигации по вымышленным страницам нет. В приложении используются только статический SVG и собственный CSS; аналитика, магазинные скрипты, сессия и содержимое сохранённого HTML не подключаются.
