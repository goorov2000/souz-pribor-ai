# Манометр показывающий DM 02 — Манотомь

> Требует проверки человеком перед публикацией.

## SEO-описание

Манометр показывающий DM 02 предназначен для измерения избыточного давления. Это назначение прямо указано в описании товара; иных подтверждённых задач применения во входных данных нет.

В таблице характеристик указан диапазон измерений 0–1,6 МПа, класс точности 1,5, присоединение G1/2 и диаметр корпуса 100 мм. В описании приведено другое значение диапазона — 0–2,5 МПа. Диапазон требует сверки по паспорту изделия; до подтверждения не следует считать одно из значений установленным.

При подборе сопоставьте требуемый диапазон давления с подтверждённым паспортным значением, проверьте соответствие класса точности задаче, а присоединение и диаметр корпуса — требованиям места установки. Известные параметры приведены выше; для согласования заказа потребуется разрешить расхождение по диапазону.

Данных нет о материале корпуса, условиях эксплуатации и других характеристиках, не указанных во входных данных. Для подбора уточните по паспорту реального изделия подтверждённый диапазон и необходимые дополнительные параметры монтажа и применения.

## Для менеджера

Подходит для задач измерения избыточного давления. Перед подбором и заказом необходимо сверить диапазон измерений по паспорту: в исходных данных указаны разные значения.

## Требует уточнения

- specs.диапазон измерений
- Во входных данных расходятся значения диапазона измерений: в specs указано 0–1,6 МПа, в description — 0–2,5 МПа. Требуется сверка по паспорту.
- Черновик: проверьте смысл, назначение и полноту по паспорту перед публикацией.
- Противоречие: диапазон измерений. В характеристиках: 0–1,6 МПа; в описании: 0–2,5 МПа. Цитата: «Диапазон измерений: 0–2,5 МПа.».
