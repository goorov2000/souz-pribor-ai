# Нужны дополнительные сведения

Датчик температуры ТД-01 предназначен для измерения температуры. Указан диапазон измерений −20…+80 °C; этого параметра недостаточно для полноценного описания и оценки соответствия прибора конкретным условиям применения. Для подготовки карточки нужны сведения о точности, конструкции и способе установки, условиях эксплуатации и других характеристиках. Источник обозначен как учебный пример, а не паспорт изделия.
